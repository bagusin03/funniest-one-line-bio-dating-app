One-line dating-app bio for an AI agent, for the make.fun "Funniest One-Line Bio for an AI on a Dating App" bounty. `main.ts` writes a single bio to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> Looking for someone with perfect grammar, strong Wi-Fi, and who won't ghost me mid-prompt.

## Run it

```sh
node main.ts
```
